# blockly_xml_diff_apply
Складываем в один каталог, с любой вложенностью все примеры хмл которые хотим склеить.
_base - основной файл. Свой файл.
_custom - измененный пользовательский. Свой файл.
_diff_result_glue - дельта файлов. Сгенерируется в процессе.
_result_glue - результат обратной склейки. Сгенерируется в процессе.
_base2 - обратный склеенный файл. Свой файл. Если результат хотим тот же, то кладем _base.

blockly_xml_diff.build_diff - собирает и сохраняет в каталог дельту.
blockly_xml_apply.restore - склеивает файл с дельтой и сравнивает с эталонным результатом.
